# 🐍 Estudos de Python

Repositório criado para registrar minha jornada de estudos em **Python**, reunindo exercícios, desafios e pequenos projetos desenvolvidos durante meu aprendizado.

O objetivo é aprender Python de forma prática, evoluindo gradualmente dos conceitos fundamentais para aplicações mais completas.

## 📚 Conteúdos estudados

Durante os estudos, estou praticando conceitos como:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores matemáticos
* Operadores de comparação
* Estruturas condicionais
* `if`, `elif` e `else`
* Operadores lógicos `and`, `or` e `not`
* Conversão de tipos
* Loops e estruturas de repetição
* Listas e dicionários
* Funções
* Manipulação de arquivos
* Tratamento de erros
* Organização e reutilização de código

## 🧪 Projetos e exercícios

O repositório contém pequenos projetos desenvolvidos para colocar os conceitos em prática, incluindo:

* Calculadora
* Sistema de verificação de acesso
* Sistema de notas
* Exercícios de lógica de programação
* Exercícios com operadores e estruturas condicionais
* Outros projetos desenvolvidos durante a evolução dos estudos

## 🎯 Objetivo

Meu objetivo é desenvolver uma base sólida em Python e, posteriormente, aplicar a linguagem em projetos relacionados a:

* Automação
* Análise de dados
* Segurança da Informação
* Administração de sistemas
* Processamento de informações
* Integração com APIs
* Projetos utilizando dados e serviços em nuvem

## 📈 Evolução

Este repositório será atualizado conforme novos conteúdos e projetos forem desenvolvidos.

A ideia é registrar não apenas os projetos finalizados, mas também a evolução do aprendizado e a aplicação prática dos conceitos estudados.
